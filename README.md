Dapur Membara — a timed wok-station cooking game. A chef runs a small Indonesian kitchen through a 180-second service day: take rice, noodles, chicken, vegetables, chili and egg from the pantry, chop the raw items on the board, cook a base plus a chopped item in one of two woks, plate the dish with its topping, and serve it at the window before the ticket on the order board runs out. Six dishes combine the same stations in different ways, a combo multiplier rewards clean chains up to 3x, and a rush hour in the last minute doubles the order pace. A wok left too long burns, a wrong dish costs coins, and every sound is synthesised WebAudio. It plays with keyboard and mouse on desktop, with no network request at all. Best service is kept in the browser's local storage on the player's own machine.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
